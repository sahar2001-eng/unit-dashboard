    How to add a run

    1. From a video (on the Mac, in the runkit folder):
      python3 run.py video clip.mp4 --tile 2
      Runs the camera's own code over every frame and makes a run folder.
    2. From a robot drive: python3 run.py record --cam 192.168.4.1 (saves the camera stream; Ctrl+C stops)
    3. Upload: python3 run.py upload runs/<folder>, or zip the folder and drop it below.

    Drop a run here (.zip)

    The zip holds info.json, frames.csv and video.mp4.
